# ez-ai-catalogo

Catálogo assinado de pacotes do [ez-ai](https://github.com/educarvalhoo/ez-ai), usado por `ez-ai search`. Veja o guia em docs/guias/catalogo-de-pacotes.md do ez-ai.

Para incluir um pacote, abra um PR editando `catalogo.json`. A cada tag `v*` o workflow assina o conteúdo exato do arquivo com Sigstore. Estar na lista não significa que o pacote foi revisado.
